## 一、为什么要再来一轮

上一轮（`2026-07-16-2notes-ui-优化设计.md`）已把主窗口迁到 UnoCSS 并引入双主题，视觉基线可用。当前距"大厂桌面应用"的差距不在缺功能，而在两点：**体系不统一**、**视觉噪音过高**。以下问题均已对代码核对。

### 分类 A：体系分裂

- **A1 样式双轨制**。`AppShell.vue` / `EntryList.vue` / `EntryListItem.vue` / `EntryDetail.vue` 已全量 utility class；`SettingsView.vue`(642 行)、`QuickCapture.vue`(319 行)、`EmptyState.vue` 仍是 scoped CSS 自成一套。同一个"设置行/面板"在两处有两种实现。
- **A2 排版无 scale**。11/12/13/14/15/24px 以 `text-[13px]` 形态硬编码散落 30+ 处，无 token，改一次要全局搜。
- **A3 动效令牌两套**。`main.css` 定义 `--duration-fast/normal` + `--ease-standard`；`uno.config.ts` 又定义 200ms + `cubic-bezier(0.16,1,0.3,1)` 和 spring。且 `scale-spring` / `fade-in` / `pulse-saved` 三个 keyframes 定义了基本没用。
- **A4 焦点态三套**。`ring-focus`(shortcut)、`shadow-focus`(topbar 搜索框 `focus-within:shadow-focus`)、`focus-visible:shadow-[inset_0_0_0_2px]`(EntryList 容器)。
- **A5 文档与实现脱节**。07-16 文档写品牌色青绿 `#0f6978`，实现是 `#2563eb`。

### 分类 B：视觉噪音

- **B1 过度依赖 1px 线分层**。sidebar `border-r`、topbar `border-b`、list `border-r`、list header `border-b`、**每个列表项 `border-b`**、detail header `border-b`、detail 卡片 `border`、控制区 `border-y`、标签区 `border-b` —— 一屏最多 9 条硬线，观感接近表格而非现代应用。
- **B2 选中态过重**。`bg-brand-subtle` + `inset 2px brand` 左条，在长列表里是大面积高饱和蓝块；且 hover 用 `bg-bg-hover`（中性）与选中（蓝）不同色系，移动时有色相跳变。
- **B3 阴影兼任描边**。`--shadow-*` 内嵌 `0 0 0 1px var(--color-border-subtle)`，凡 `shadow-md` 元素自身又有 border 就出双线（错误提示条、标签面板、SaveState 均命中）。
- **B4 chrome 三层堆叠**。topbar 56 + list header 44 + detail header 44。且 detail header 左侧完全空白、只有右侧按钮，重心失衡。
- **B5 毛玻璃滥用**。`glass-panel`(backdrop-blur-xl) 同时用于 sidebar、topbar、detail header。sidebar 之下无滚动内容，模糊无意义；深色主题下整体发灰。

### 分类 C：细节精度

- **C1 大字号缺负字距**。24px 标题 `letter-spacing: 0`，视觉松散（≥20px 通常需 -0.01~-0.02em）。
- **C2 数字对齐不一致**。列表时间与计数用 `tabular-nums`，设置页与其它计数没有。
- **C3 色相不成体系**。brand 蓝 `#2563eb` / danger 土红 `#a03336` / success 墨绿 `#167246` / warning `#b45309`，饱和与明度曲线各自为政，同屏像三个产品。
- **C4 廉价交互反馈**。`active:scale-98` / `active:scale-95` 用在导航项、列表按钮这类高频目标上，桌面端按压缩放是移动端语汇，且引起抖动。
- **C5 空状态定位错**。`EmptyState` 固定 `min-height:160px`，在 EntryList 的 `flex-1` 容器里贴顶显示，不在视觉中心。
- **C6 无骨架屏**。加载态是"加载中"文字 + spinner，视图切换布局闪跳。
- **C7 列表元信息层级平**。知识 / 类型 / 状态 / 标签 同色同字号一串灰字，扫读无锚点；`tags.slice(0, 1)` + `+N` 处理生硬。
- **C8 设置页导航是伪导航**。只做 `scrollToSection`，无 active 态、无当前分类反馈。
- **C9 QuickCapture 与既定目标不符**。面板铺满窗口 + 1px 边框，非 07-16 文档所说的"居中聚焦卡片"。

## 二、设计原则

大厂桌面应用（Linear / Things / Apple Notes / Craft）的共性不是"更多装饰"，而是这五条约束：

1. **减线增空**。层级优先用背景明度差 + 间距表达，1px 线只在语义必须处保留（如 topbar 与内容的分界）。
2. **彩色是稀缺资源**。品牌色只用于主操作、焦点环、当前导航项标记。选中态用中性提升层，不用彩色填充。
3. **单一 token 来源**。任何字号 / 间距 / 圆角 / 阴影 / 时长只允许一个定义处，组件内不出现裸像素值。
4. **状态用不透明度与背景过渡，不用位移**。桌面端不做按压缩放。
5. **密度优先于留白**。这是重度输入工具，扫读效率 > 视觉宽松。故取 Linear 的紧凑而非 Notion 的松散。

## 三、令牌层重构

### 3.1 排版 scale（新增）

在 `main.css` 定义，`uno.config.ts` 的 `theme.fontSize` 映射为 `text-display/title/...`，替换全部 `text-[Npx]`：

| token | size | line-height | weight | tracking | 用途 |
|---|---|---|---|---|---|
| `display` | 24px | 32px | 680 | -0.02em | 详情页标题输入 |
| `title` | 17px | 24px | 620 | -0.01em | 设置页 h1、QuickCapture h1 |
| `heading` | 14px | 20px | 600 | -0.005em | 区域标题、topbar 视图名 |
| `body` | 13.5px | 22px | 400 | 0 | 正文编辑器、详情内容 |
| `ui` | 13px | 20px | 400 | 0 | 按钮、输入、导航、列表标题 |
| `caption` | 12px | 18px | 400 | 0 | 摘要、说明文字 |
| `micro` | 11px | 16px | 500 | 0.01em | 元信息、时间、计数、kbd |

正文行高从 28px（`leading-7`）降到 22px：28px 对 14px 字号是 2.0 倍，段落散架。

### 3.2 颜色

**方案 A（推荐）保留品牌蓝，重制语义色到同一饱和/明度曲线**

- brand `#2563eb` 不动（辨识度已建立、深色 `#6ea1ff` 对比度达标）。
- danger `#a03336` → `#dc2626`，success `#167246` → `#059669`，warning `#b45309` → `#d97706`。四色统一到 chroma 相近的一档，同屏不再割裂。
- **新增中性选中层** `--color-bg-selected`：浅色 `#eceef1`、深色 `#22262e`。用于列表选中/导航选中，替代 `bg-brand-subtle` 大面积填充。
- `brand-subtle` 降级为仅用于搜索高亮 `<mark>` 与徽标底色。
- 效果：主界面彩色面积从约 15% 降到 5% 以下。

**方案 B 回到 07-16 文档的青绿 `#0f6978`**
辨识度更强、更"产品化"；代价是深色主题需重算全套对比度，且与 success 绿易混淆。

> **默认执行方案 A**。选 B 请明确告知，会追加一节深色映射表。

### 3.3 阴影：描边与投影解耦

`--shadow-*` 移除内嵌 `0 0 0 1px`，改为纯投影，消除 B3 双线。配套四级 elevation 规则：

| level | 用法 | 样式 |
|---|---|---|
| 0 | 页面底、常驻面板 | 无阴影，靠 `bg` 明度差分层 |
| 1 | 卡片、内联提示 | 无阴影 + `border` |
| 2 | 浮层（标签面板、建议列表、SaveState） | `shadow-md` + `border` |
| 3 | 模态（ConfirmDialog） | `shadow-xl` + `border` |

### 3.4 动效收敛

- 只留三个时长：`--duration-fast: 120ms`（hover/焦点）、`--duration-base: 180ms`（面板/浮层）、`--duration-slow: 240ms`（模态）。
- 只留一条曲线 `--ease-out: cubic-bezier(0.16, 1, 0.3, 1)`，删除 `--ease-standard`。
- 删除 `uno.config.ts` 中未使用的 `scale-spring` / `pulse-saved`，保留 `fade-in` 并接入时长 token。
- 删除全部 `active:scale-*`（C4），按压改为 `active:bg-*` 加深一档。

### 3.5 焦点环统一

保留 `ring-focus` 一个入口（`focus-visible:ring-3` + `--color-focus-ring-bg`），删除 `shadow-focus` / `focus-glow` / `focus-visible:shadow-[inset...]` 三种变体。容器级焦点（EntryList）改用 `ring-inset`。

## 四、组件规格

  - 若担心 topbar 拥挤，退一步方案：detail header 保留但降到 40px，左侧补面包屑（`收集箱 / 标题`）填补空白。

### 4.2 SidebarNav

### 4.3 EntryList / EntryListItem

- 列表容器去右边框，靠 `bg-elevated` 与详情区 `bg-secondary` 的明度差分层。

- 选中态：`bg-selected` + 左侧 2px `bg-brand`（`inset` 阴影改 `border-l`，避免阴影语义混用）。

- 空状态：`EmptyState` 增加 `fill` 变体（`h-full` + 垂直居中），修 C7 顶部堆积。
- 加载：新增 `SkeletonText` 组件，首屏渲染 6 条骨架项（标题条 + 两行摘要条），替代「加载中」文字，消除 C7 布局抖动。

### 4.4 EntryDetail

- 标题输入走 `display` token（24px/680/-0.02em），负字距是"大厂感"最直接的来源之一。
- 卡片 `article` **去边框**，改 `bg-elevated` + `rounded-lg` + elevation 1；内部 `border-y` 分组线保留（此处语义必要）。

- SaveState 从 `fixed bottom-4 right-4` 移到 topbar 右侧内联（与 4.1 合并方案配套）。浮动药丸在窄窗口会压住正文。

## 六、验收标准

视觉：

- 主界面（sidebar + topbar + 列表 + 详情）可见 1px 硬线 ≤ 4 条。
- 品牌色着色面积（默认态截图取样）≤ 5%；选中态为非彩色填充 + 彩色细条。
- 不存在同时带 `border` 与 `box-shadow` 描边的元素。
- 所有字号来自 token，`grep -rE 'text-\[[0-9]+px\]' src/` 结果为空。
- 双主题下正文 / 次级文字对比度 ≥ 4.5:1，三级文字 ≥ 3:1。

交互：

- 焦点环仅一种实现；`grep -r 'shadow-focus\|focus-glow' src/` 为空。
- Tab 可遍历全部可交互元素，顺序符合视觉顺序。
- 无 `active:scale-*`；`grep -r 'active:scale' src/` 为空。
- 所有过渡 ≤ 180ms，仅使用 `--ease-standard` / `--ease-out`。
- 列表首次加载与视图切换显示骨架屏，无布局跳动。
- `prefers-reduced-motion: reduce` 下动画有效关闭。

工程：

- `pnpm lint` / `pnpm typecheck` / `pnpm test:unit` / `pnpm build` 全绿。
- `src/components/**/*.vue` 中 scoped CSS 仅保留 Vue `<Transition>` 类与无法用 utility 表达的选择器。
- 不新增运行时依赖。
- 现有单测不因样式重构失败；EntryListItem 去分割线后需同步更新快照/类名断言。

## 七、非目标

- 不新增产品功能（不做 Markdown 预览、不做拖拽排序、不做多窗口）。
- 不引入 UI 组件库、动画库、图标库替换（继续用 lucide）。
- 不做移动端适配，只保证 ≥ 900px 桌面窗口与最小 320px 不崩。
- 不做国际化。
