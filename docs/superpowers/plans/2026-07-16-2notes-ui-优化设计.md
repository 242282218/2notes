# 2notes UI 美学与交互优化设计

日期：2026-07-16

## 目标

把 2notes 从当前“功能可用”的视觉层级提升到 Apple 式大厂桌面应用质感：干净、柔和、有层级、响应及时、深浅主题可用、键盘可访问。本轮不扩展产品功能，只改造视觉层、布局层和交互反馈层。

成功标准：

- 全局视觉风格统一，具有明显的 Apple 式 clean aesthetic。
- 支持浅色/深色双主题，默认跟随系统，用户可手动切换并持久化。
- 关键交互（按钮、输入、列表、保存状态、对话框）有清晰、克制的反馈。
- 键盘可访问性增强：列表导航、标签建议、WikiLink 补全、焦点环。
- 不改后端数据模型、存储、API 契约；允许为适应新布局微调组件 props/events，但不改变业务语义。
- 改动后必须跑通 `pnpm run lint`、`pnpm run typecheck`、`pnpm run test:unit`、`pnpm run build`。

## 视觉方向

### 设计语言

- 柔和、低饱和、中性偏暖的调色板。
- 更大的圆角（8–12px），更淡更分散的阴影。
- 纯白/深灰卡片浮在浅灰/深灰背景上，形成层级。
- 字体层级清晰：页面标题 20px、区域标题 16px、列表标题 14px、正文 14px、辅助 12–13px。
- 品牌色保持青绿色系（#0f6978 附近），用于主按钮、聚焦环、选中指示、保存成功提示。

### 设计令牌

在 `:root` 和 `[data-theme="dark"]` 下定义 CSS 变量：

- 颜色：`--color-bg-base`、`--color-bg-elevated`、`--color-bg-hover`、`--color-border`、`--color-text-primary`、`--color-text-secondary`、`--color-text-tertiary`、`--color-brand`、`--color-brand-hover`、`--color-danger`、`--color-success`。
- 间距：`--space-1` 到 `--space-8`（4px 步进）。
- 圆角：`--radius-sm: 6px`、`--radius-md: 8px`、`--radius-lg: 12px`、`--radius-full: 999px`。
- 阴影：`--shadow-sm`、`--shadow-md`、`--shadow-lg`（浅色明显，深色更弱）。
- 动效：`--duration-fast: 120ms`、`--duration-normal: 180ms`、`--ease-out: cubic-bezier(0.16, 1, 0.3, 1)`。

## 布局与 Shell

### 主窗口

当前两栏（sidebar + workspace）保持不变，但视觉升级：

- 左侧导航栏从 176px 收窄到 64–180px（响应式：宽屏显示标签，窄屏只显示图标）。
- 导航项使用图标 + 文字，active 状态使用柔和背景 + 品牌色图标 + 左侧 3px 指示条。
- workspace 顶部 topbar 更紧凑，搜索框使用无边框浅色背景，聚焦时显示品牌色描边。
- content-area 保持三栏可变布局（tags-panel / entry-list / entry-detail），但在宽屏下调整为更舒适的 200px / 34% / 1fr。

### 条目列表

- 列表项增加左侧 3px 圆角选中指示条（`border-radius-left` 效果）。
- padding 从 12px 14px 增加到 14px 16px，增加呼吸感。
- 标题使用 semibold，摘要保持两行 clamp，元信息更紧凑。
- 空状态增加图标和辅助文案；加载状态使用骨架屏或淡入占位。

### 详情页

- 标题输入放大到 24px、font-weight 700，placeholder 更明显。
- 控制区（类型、状态、标签）使用卡片式分组。
- 正文编辑器增加最小高度和更舒适的行高（1.65）。
- 原始内容区默认折叠，但 summary 样式更友好。
- 知识关系区使用更清晰的卡片分组。
- 保存状态移到右下角药丸形提示（保存中 → 已保存 → 失败可重试）。

### 设置页

- 从单栏长列表改为左侧设置分类 + 右侧内容的布局（宽屏），小屏保持单栏。
- 每行设置项增加说明文字和控件的对齐。
- 新增“外观”分类，包含主题切换（跟随系统 / 浅色 / 深色）。

### 快速记录窗口

- 从全屏铺满改为居中聚焦卡片，四周留出柔和遮罩感（实际仍占满 Tauri 窗口，但视觉居中）。
- 标题栏更轻，footer 按钮更明确。
- 呼出/隐藏增加 opacity + translateY 的淡入淡出。

## 组件细节

### 按钮

- 默认圆角 8px，高度 32–38px。
- 主按钮：品牌色填充，hover 加深，active 再加深。
- 次按钮：浅灰背景或白色背景 + 细边框。
- 危险按钮：红色系，hover 加深。
- IconButton：34×34，hover 背景从圆形改为 8px 圆角。
- 所有按钮增加 `:active` 缩放（`scale(0.97)`）和 120ms 过渡。

### 输入框与选择器

- 聚焦时显示 2px 品牌色描边 + 2px 柔和外发光（`box-shadow`）。
- disabled 状态降低透明度并去掉聚焦环。
- 下拉选择器增加自定义箭头图标。

### 标签输入

- 标签胶囊更紧凑，高度 24px，圆角 full。
- 输入区与胶囊混排更自然。
- 建议下拉增加键盘高亮项的品牌色左边框。

### WikiLink 补全

- 补全面板保持现有位置，但视觉升级为卡片式浮层。
- 高亮项使用品牌色背景 + 左边框。
- 保留并增强 ArrowUp/ArrowDown/Enter/Escape 键盘行为。

### 对话框

- 进入动画：opacity 0→1 + scale 0.96→1，180ms ease-out。
- 按钮顺序符合平台习惯（Windows：主操作在左；但 Apple 风格可将主操作放右，这里统一为右侧主操作）。
- 增加关闭按钮或点击 backdrop 取消。

## 主题系统

1. 使用 CSS 自定义属性定义所有与颜色相关的样式。
2. `html` 元素设置 `data-theme="light" | "dark"`。
3. 默认 `data-theme` 通过 `window.matchMedia('(prefers-color-scheme: dark)')` 推断。
4. 设置 store 增加 `themeMode: 'system' | 'light' | 'dark'` 字段，持久化到 SQLite 设置表。
5. 监听系统主题变化，当 `themeMode === 'system'` 时自动切换。
6. 切换动画通过 CSS transition 在颜色变量上实现，避免闪烁。

## 动效与微交互

- 基础过渡：`transition: color var(--duration-fast), background-color var(--duration-fast), border-color var(--duration-fast), box-shadow var(--duration-fast), transform var(--duration-fast)`。
- 列表项 hover/active：背景色 120ms 过渡。
- 按钮 active：scale 0.97，120ms。
- 对话框/下拉：opacity + scale/translateY，180ms ease-out。
- 保存状态：文字/图标切换使用 crossfade 或 opacity 过渡。
- 快速记录窗口：opacity + translateY(8px→0)。
- 自定义滚动条：细线风格，颜色随主题变化，hover 变宽。

## 键盘与可访问性

- 所有图标按钮必须有 `aria-label`。
- 列表支持 ArrowUp/ArrowDown 导航，Enter 打开，Delete 移入回收站（非回收站视图）。
- 标签建议和 WikiLink 建议支持 ArrowUp/ArrowDown、Enter 选择、Escape 关闭。
- 输入框聚焦环使用 `outline: 2px solid brand` + `outline-offset: 2px`，不依赖浏览器默认。
- 颜色对比度满足 WCAG AA。

## 文件改动范围

新增/大幅修改：

- `src/styles/main.css`：重写为基于 CSS 变量的设计系统。
- `src/styles/theme.css`：浅色/深色变量定义（或合并到 main.css）。
- `src/composables/useTheme.ts`：主题检测、切换、持久化。
- `src/components/settings/AppearanceSettings.vue`：外观设置分类。
- `src/components/shared/ThemeToggle.vue`：主题切换开关。
- `src/components/layout/AppShell.vue`、`SidebarNav.vue`：布局与导航升级。
- `src/components/entry/EntryList.vue`、`EntryListItem.vue`：列表视觉升级。
- `src/components/entry/EntryDetail.vue`：详情页卡片化。
- `src/components/quick-capture/QuickCapture.vue`：快速记录视觉升级。
- `src/components/settings/SettingsView.vue`：设置页布局调整。
- `src/components/shared/IconButton.vue`、`ConfirmDialog.vue`、`SaveState.vue`：组件细节升级。
- `src/stores/settings.ts`：增加 `themeMode` 字段与持久化。

不改动：

- Rust 后端代码、`src-tauri/` 业务逻辑。
- 数据模型、API 契约、composables 核心逻辑（`useAutosave`、`useWikiLinkCompletion` 等）。
- 测试覆盖的业务语义，仅同步更新因 DOM/类名变化失效的测试。

## 非目标

- 不引入新的 UI 组件库（仍只使用 Vue 3 + UnoCSS + 自定义组件）。
- 不改窗口管理、系统托盘、全局快捷键逻辑。
- 不增加新功能（如云同步、图谱、附件、AI）。
- 不做复杂动画库集成（仍使用 CSS transitions + Vue `<Transition>`）。
