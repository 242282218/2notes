# 2notes 全量审查问题顺序修复实现计划

> **面向 AI 代理的工作者：** 按任务顺序内联执行。每个生产代码修改前必须先运行对应失败测试。当前工作树包含用户未提交改动，不创建任务级 commit，避免把既有修改误提交。

**目标：** 严格按全量审查顺序修复 23 个已确认问题，并恢复完整质量门禁。

**架构：** 保留现有 Vue/Pinia/Tauri/SQLite 边界。前端问题在组件或 store 的现有状态边界修复；备份恢复通过更严格的候选校验、可恢复文件交换和连接重建保证数据安全；工程问题通过明确扫描范围、版本门禁和最小权限检查解决。

**技术栈：** Vue 3、TypeScript、Vitest、Pinia、Tauri 2、Rust、rusqlite、PowerShell、GitHub Actions。

## 文件职责

- `src/components/quick-capture/QuickCapture.vue`：草稿水合、自动保存、输入法与恢复事件。
- `src/components/quick-capture/QuickCapture.test.ts`：快速记录并发、输入法、恢复回归。
- `src/components/entry/TagInput.vue`：标签草稿提交和键盘交互。
- `src/components/entry/TagInput.test.ts`：标签输入、导航和输入法回归。

- `src/components/entry/EntryDetail.test.ts`：自动标题补丁和可访问性回归。
- `src/stores/entries.ts` / `src/stores/entries.test.ts`：列表、选择和写操作错误状态。
- `src-tauri/src/files/backups.rs`：备份验证、文件交换、连接恢复、元数据。
- `src-tauri/src/files/paths.rs`：启动回滚恢复和显式测试数据根目录。
- `src-tauri/src/commands/*.rs`：阻塞任务调度和调用窗口授权。
- `src-tauri/src/app_state.rs` / `system/windows.rs` / `system/tray.rs`：退出请求取消和强制退出。
- `src-tauri/src/db/repos/entries_repo.rs`：FTS 优先查询。
- `scripts/test/*.ps1`：隔离冒烟、严格审计和版本一致性。
- `.github/workflows/*.yml`、`package.json`、`eslint.config.js`、`vitest.config.ts`：CI、发布和扫描边界。
