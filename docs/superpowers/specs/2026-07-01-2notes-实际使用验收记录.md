## 已确认问题

### 快速记录保存后主窗口不刷新

复现路径：

1. 启动 release 版。
2. 在主窗口点击“记录”。
3. 快速记录窗口输入内容并保存。
4. SQLite 中新增记录，草稿清空。
5. 主窗口仍显示“暂无条目”。

结论：数据写入成功，但主窗口没有收到记录变更通知，真实使用时会误判为保存失败。

修复：

- `quick_capture_submit` 在事务提交后向 `main` 窗口发送 `entries-changed` 事件。
- `AppShell` 监听 `entries-changed`，重新加载列表和标签。

复测结果：

- 快速记录保存后，SQLite 新增记录。
- 主窗口文本立即包含新记录。
- 草稿清空。
- CDP 运行时未捕获 console 异常。
- 进程保持 `Responding=True`。
