# 2notes 全量审查问题顺序修复设计

日期：2026-07-15

## 目标

严格按照 2026-07-15 全量代码审查中的严重级别和条目顺序修复问题。每个非配置类问题都先增加能够稳定复现缺陷的失败测试，再用最小实现修复根因，最后运行局部测试和完整门禁。

本轮不新增产品功能，不重构无关模块，不改变现有数据模型的产品语义。

## 执行顺序

### 第一阶段：P1 数据与发布安全

1. 快速记录并发保存时推进 stale revision。
2. 拒绝零字节、无 2notes schema 或无迁移记录的备份。
3. 消除数据库恢复两次独立重命名造成的无数据库启动窗口，并在启动时恢复遗留回滚文件。
4. 快速记录和标签输入忽略输入法组合期间的 Enter。
5. 数据库恢复后同步已存在的快速记录窗口。
6. 条目加载失败时清除旧详情，禁止选中项与编辑对象错位。
7. 修复 CDP 测试数据目录隔离与清理。
8. 为 GitHub Release 声明 `contents: write`。

### 第二阶段：P2 稳定性与工程门禁

9. 恢复失败时始终重建有效数据库连接，并准确区分恢复成功与回滚成功。
10. 标签失焦时同步提交草稿，避免导航丢失或跨条目写入。
11. 保留自动标题语义，只有用户实际修改标题时才发送标题补丁。
12. 将备份、恢复和 Markdown 导出中的阻塞工作移出 Tauri 主线程。
13. 严格处理 RustSec 的 unsound 警告，并替换被标记的不健全直接依赖。
14. 限定 ESLint 和 Vitest 的项目扫描边界。
15. 为列表及删除、恢复、永久删除失败提供可见错误状态。
16. 为退出握手增加有限等待和可恢复的强制退出路径。
17. 调整搜索路径，避免 FTS 命中时仍对全部活动条目执行 `%LIKE%` 扫描。
18. 固定 pnpm 版本，并确保 CI 使用的测试脚本纳入版本控制。

### 第三阶段：P3 契约与可访问性

19. 统一备份时间格式并正确识别带碰撞序号的备份类型。
20. 收紧快速记录窗口可调用的后端命令边界。
21. 为核心编辑控件增加可访问名称，并支持键盘选择标签建议。
22. 增加发布标签与应用版本一致性检查。
23. 修正文档中的 Markdown 导出范围说明。

## 设计原则

### 前端状态

- `useAutosave` 继续作为唯一保存串行化机制，组件必须完整处理 `onSaved` 和 `onStaleSaved`。
- 数据库恢复通过应用事件通知其他窗口重新水合，不引入额外全局状态框架。
- 输入法处理统一在键盘事件边界检查 `event.isComposing`。
- 选择、列表和写操作失败必须清除不可信的旧状态并显示现有 store 错误字段。

### 数据库恢复

- 候选备份必须在替换前验证 SQLite 完整性、应用 schema 和迁移版本。
- 文件替换失败后，`AppState` 中不得留下内存占位连接。
- 启动时若正式数据库缺失但存在恢复回滚文件，优先恢复回滚文件，禁止静默创建空库。
- 恢复目标失败但旧库回滚成功时，命令必须返回失败，不能向前端报告目标恢复成功。

### 工程化

- 前端测试只收集 `src/**/*.test.ts`，lint 只检查本项目源码和根配置。
- Rust 审计对 `unsound` 直接失败；目标平台无关的 unmaintained 传递依赖不在本轮强行替换。
- GitHub Release 显式声明最小写权限，并在发布前检查标签版本。
- CDP 测试通过应用支持的测试数据目录覆盖实现隔离，不依赖修改 Windows 的 `APPDATA` 环境变量。

## 测试策略

- Vue 组件和 store 问题使用 Vitest 与 Vue Test Utils。
- SQLite、备份、恢复和迁移问题使用 Rust 单元测试及临时目录。
- Tauri 跨窗口事件将可测试逻辑下沉为小型纯函数或通过现有事件 payload 测试。
- 工作流和脚本配置使用可重复的命令级验证。
- 每完成一个条目，运行该条目的最小测试；每个阶段完成后运行对应完整测试集。

## 最终验收

以下命令必须全部通过：

```powershell
pnpm run format:check
pnpm run lint
pnpm run typecheck
pnpm run test:unit
pnpm run build
pnpm run audit:frontend
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo test --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets --all-features -- -D warnings
pnpm run audit:rust
pnpm run tauri:build
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test/2notes-quick-capture-cdp.ps1
```

严格 Rust 审计必须对项目直接依赖的 unsound advisory 返回失败；完成依赖替换后应恢复为通过。

## 非目标

- 不增加云同步、账号、AI、附件或新的备份格式。
- 不重写现有 store、repository 或窗口系统。
- 不处理只影响其他操作系统、且 Windows 目标不加载的传递依赖维护警告。
