## 规模验证

- 本地 release，10,000 条目、正文约 500 个中文字符、每条 3 个 WikiLink：
  - 索引重建：4381.84 ms。
  - trigram 搜索 p95：286.41 ms，低于 300 ms 门限。
  - 知识库首页读取 p95：2.55 ms，低于 300 ms 门限。
- 单条正文包含 100 个 WikiLink，20 次保存 release p95：2.64 ms，低于 100 ms 门限。
- `EXPLAIN QUERY PLAN`：三字查询使用 FTS `VIRTUAL TABLE`，生产 SQL 不含 `%LIKE%` 全表扫描；短查询按设计走 LIKE 回退。
- 门禁调试期间曾复现 306.32、306.99、303.75 ms 的边缘失败；根因是显式 `bm25()` 通用排序和默认页面缓存使查询贴近门限。改用 FTS5 `rank` 通道并设置 32 MiB SQLite 页面缓存后，连续复验和最终门禁均通过；未放宽 300 ms 门限。
- 测试机复核：阻断。测试机剩余磁盘和内存不足且无 Rust 工具链，安全安装或编译会影响现有服务，未在该机器执行 release 性能复核。
